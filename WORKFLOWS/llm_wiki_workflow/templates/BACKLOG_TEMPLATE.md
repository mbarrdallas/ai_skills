# Backlog

Wiki-content backlog for this repo — follow-up items discovered during
ingest/query/lint that aren't safe to fix immediately (need a human
decision, a new source, or more content). Not to be confused with
`WORKFLOWS/llm_wiki_workflow/BACKLOG.md`, which tracks future work on the
*shared workflow itself*, not this repo's content.

Checkbox format: `- [ ]` open, `- [x]` done. Group by domain if this grows
long. Cite the page/source an item came from so it's actionable without
re-deriving context.

`knowledge-ingest-agent` checks off relevant items opportunistically while
already touching related content; `knowledge-lint-agent` re-checks open
items during each lint pass in case something else already resolved them.
